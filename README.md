# Prolog-Riddle-Solver
Welcome to Prolog Riddle Solver! This repository contains a collection of tricky riddle questions and their solutions implemented in Prolog.
Here, you will find logic puzzles, riddles, and challenges solved using declarative programming concepts in Prolog.

## Purpose
The main goal of this repository is to demonstrate the power of Prolog in solving logical riddles and puzzles by encoding facts, rules, and queries. 
It serves as both an educational resource and a practical tool for those learning Prolog.
